# Gerenciador Financeiro em C++

Sistema de gerenciamento financeiro desenvolvido em C++17 como projeto de estudo e portfólio.

## Objetivo

Desenvolver uma aplicação para controlar receitas, despesas, dívidas e saldo financeiro, aplicando conceitos de programação orientada a objetos, persistência de dados e boas práticas de desenvolvimento.

## Tecnologias

- C++17
- CMake
- Git e GitHub
- SQLite (planejado)

## Funcionalidades planejadas

- Cadastro de receitas e despesas
- Consulta de saldo
- Gerenciamento de dívidas
- Cadastro e autenticação de usuários
- Armazenamento de dados com SQLite
